# Lizenz

Dieses Repository enthält zwei Arten von Inhalten, für die unterschiedliche Lizenzen gelten: Lehrmaterial (Texte und Abbildungen) und Code. Die Aufteilung folgt der Empfehlung von Creative Commons, CC-Lizenzen nicht für Software zu verwenden, und dem Modell der Lehrmaterialien von [The Carpentries](https://carpentries.org/).

## Lehrmaterial: CC BY 4.0

Alle Texte und Abbildungen in diesem Repository stehen, soweit nicht anders angegeben, unter der Lizenz [Creative Commons Namensnennung 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/deed.de). Maßgeblich ist der [Lizenzvertrag](https://creativecommons.org/licenses/by/4.0/legalcode.de).

Sie dürfen das Material vervielfältigen, weiterverbreiten und bearbeiten, auch für kommerzielle Zwecke. Dabei müssen Sie angemessene Urheber- und Rechteangaben machen, einen Link zur Lizenz beifügen und angeben, ob Sie Änderungen vorgenommen haben. Wie Sie das Buch zitieren, steht in der Datei [`CITATION.cff`](CITATION.cff).
